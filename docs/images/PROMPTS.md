# Diagramas anteriores

Los PNG de esta carpeta son iteraciones históricas de la clase. Ya no describen el despliegue actual: algunas muestran KServe o KubeRay. El README usa únicamente [el diagrama vigente](../diagrams/frutas-eks.png), generado desde [su fuente Mingrammer](../diagrams/frutas-eks.py).

Para regenerarlo, instalá Graphviz y el paquete Python `diagrams`, y ejecutá `python3 docs/diagrams/frutas-eks.py` desde la raíz del repositorio.
